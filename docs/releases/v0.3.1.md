# DSavE 0.3.1: safer restores, backup notes and Keep

Fixes from an audit of restores and game card handling, plus notes and a Keep mark for backups.

## Fixed
- **Honest restore messages.** A failed restore only says "old save kept" after it has read the old save back. Otherwise it says *Restore failed; restore the Auto backup*.
- **Pulling a game card.** Removing the card now stops reads and writes at once with "card removed", instead of a long freeze or an all-0xFF backup.
- **Full SD card.** A failed first save no longer leaves a part-written file where the kernel loads it, and a rollback no longer leaves the save at the wrong size.
- **Progress bar.** It no longer freezes on chips over 1 MB.

## New
- **Backup notes.** Give a backup a short note from the Y menu; it's shown under the backup list.
- **Keep.** Mark a backup *Keep* so auto-backup pruning skips it and it can't be moved to the trash until you clear the mark.
- **Card header timeout.** Reading the slot-1 card's header now gives up if the card comes out, instead of waiting forever. (A hang there hasn't been seen on hardware.)
- A new README.

## Install
Copy `DSavE.nds` to your SD card and launch it from your flashcart or TWiLight Menu++. There is one `DSavE.nds` for everyone: it runs on the DS, DS Lite, DSi and 3DS, so download it on Windows, macOS or Linux alike. To run it on a PC, open it in melonDS or DeSmuME. Game card saves need DSavE to be started from the DSi's or 3DS's own SD card.

The source code for this version is attached below as a zip and a tar.gz.

> Game card and emulator saves still haven't been tested on real hardware. Keep your own copy of anything precious, and please report anything that goes wrong.
