# DSavE 0.5.0: export everything as a .zip, and a hex viewer

Take all your saves off the console in one file, and see exactly what changed between two saves.

## New
- **Export all to .zip.** Choose *Export all to .zip* from the START menu to write `_DSavE/export/DSavE_<time>.zip`. Pick *Newest* for each game's latest backup, named after its ROM (ready for an emulator or flashcart), or *All* for every backup with its `backup.ini`, in the same folders as `_DSavE/saves`.
  - Damaged backups are left out, and compressed backups go in as plain saves.
  - The zip is read back and checked before it's kept, so a full SD card can't leave a broken zip behind.
- **Hex viewer.** Choose *View in hex* under Y to see a backup's bytes, 8 to a row, with ASCII alongside. It also works on compressed `.sav.gz` backups.
  - Press X to compare it with the current save, then with each other backup in turn.
  - Changed bytes are highlighted, the top screen lists the changed ranges, and Left/Right jump between them. Blank `0xFF` padding doesn't count as a change.
  - Nothing is ever written.

## Install
Copy `DSavE.nds` to your SD card and launch it from your flashcart or TWiLight Menu++. There is one `DSavE.nds` for everyone: it runs on the DS, DS Lite, DSi and 3DS, so download it on Windows, macOS or Linux alike. To run it on a PC, open it in melonDS or DeSmuME. Game card saves need DSavE to be started from the DSi's or 3DS's own SD card.

The source code for this version is attached below as a zip and a tar.gz.

> Game card and emulator saves still haven't been tested on real hardware. Keep your own copy of anything precious, and please report anything that goes wrong.
