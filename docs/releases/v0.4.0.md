# DSavE 0.4.0: activity history, undo and backup checks

A history of everything DSavE does, an undo for restores, and a way to check every backup at once.

## New
- **Activity history.** Every backup, restore, copy, import, export and trash is recorded in `_DSavE/log.txt`. Open *Activity history* from the START menu to see the newest 64 entries.
- **Undo a restore.** Press A on a restore or copy in the history to undo it. DSavE puts back the auto backup it made, and takes a new auto backup first, so an undo can be undone too.
- **Check all backups.** A new menu item checks every backup's size and CRC-32, with a progress bar. It lists damaged backups, backups without a `backup.ini`, empty or unfinished backup folders, and game folders that no game on the card uses. Press A to jump to that backup. Nothing is changed or deleted.

## Fixed
- A card restore stops with an error if the SD card returns less data than expected, instead of filling the gap with blank bytes.
- The EEPROM size test, which writes one byte to the card, now runs only after the auto backup has been made.
- Games with very many backups show the newest ones in the list, not an arbitrary selection.
- Damaged no$gba save headers are rejected before they're used.

## Install
Copy `DSavE.nds` to your SD card and launch it from your flashcart or TWiLight Menu++. There is one `DSavE.nds` for everyone: it runs on the DS, DS Lite, DSi and 3DS, so download it on Windows, macOS or Linux alike. To run it on a PC, open it in melonDS or DeSmuME. Game card saves need DSavE to be started from the DSi's or 3DS's own SD card.

The source code for this version is attached below as a zip and a tar.gz.

> Game card and emulator saves still haven't been tested on real hardware. Keep your own copy of anything precious, and please report anything that goes wrong.
