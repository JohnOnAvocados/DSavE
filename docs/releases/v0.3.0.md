# DSavE 0.3.0: game cards and emulator saves

Game card saves, emulator saves, imports and the game's icon.

## New
- **Game card saves (DSi mode).** On a DSi, or a 3DS running TWiLight Menu++ or Unlaunch, start DSavE from the console's SD card with a retail game in slot 1.
  - The card shows up at the top of the list, and you back it up and restore it like any other save.
  - Every read is done twice and compared, and every write is read back.
  - The card's old save is kept as an auto backup.
  - It handles 512 B, 8 KB, 64 KB and 128 KB EEPROMs, FLASH chips, and infrared cards such as Pokémon HeartGold/SoulSilver and Black/White.
- **Import saves.** Put files in `_DSavE/import/` and choose *Import a save* under Y. DSavE reads:
  - raw `.sav` (melonDS, Checkpoint, JKSM)
  - DeSmuME and DraStic `.dsv`
  - no$gba saves, packed or not
  - Action Replay `.duc` and `.dss`
  - `.sav.gz`

  A save named after a ROM on the card goes into that game.
- **Export for emulators.** *Export .sav* is for melonDS and flashcarts, and *Export .dsv* is for DeSmuME and DraStic. Exports are named after the ROM, and the kernel's padding is trimmed off when the real chip size is known.
- **Game icon.** The selected game's banner icon is shown on the top screen.
- **Keeps auto backups tidy.** Only the last 10 auto backups per game are kept; you can change the number in the menu. Older ones move to the trash.
- **Title fallback.** Games with only a Japanese banner title use their ROM file name instead.
- **Releases.** Tagging a version now builds the ROM and attaches it to a GitHub release.

## Install
Copy `DSavE.nds` to your SD card and launch it from your flashcart or TWiLight Menu++. There is one `DSavE.nds` for everyone: it runs on the DS, DS Lite, DSi and 3DS, so download it on Windows, macOS or Linux alike. To run it on a PC, open it in melonDS or DeSmuME. Game card saves need DSavE to be started from the DSi's or 3DS's own SD card.

The source code for this version is attached below as a zip and a tar.gz.

> Game card and emulator saves haven't been tested on real hardware or with real no$gba and Action Replay files yet. Keep your own copy of anything precious, and please report anything that goes wrong.
